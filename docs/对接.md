# 留影 · 对接

## 一句话

给任意消息流装一只「眼睛」：图片 / 视频 / 动图进来，视觉模型看一眼，描述 + 要点扇出给你选的出口（记忆库、SQLite、JSONL、Markdown、Webhook、自定义脚本）。

插件 id `eyes`，只绑 `127.0.0.1`，端口默认 `5188`。

## 三种接法

### ① HTTP 面板（人的入口，也是脚本的入口）

前台是面板页，所有数据都走 `/api/*`；面板只是其中一个客户端，脚本可以直接调。

| 方法 | 路径 | 作用 | 要不要 token |
|---|---|---|---|
| GET | `/api/health` | 探活：`ok` / `id` / `version` / `uptime_s` | 不要 |
| GET | `/api/manifest` | 身份 + 运行态：`metadata` 原样 + `runtime{port,pid,started_at}` | 不要 |
| GET | `/api/status` | 配置（key 打码）、今日/累计用量、ffmpeg 可用性 | 不要 |
| GET / POST | `/api/config` | 读 / 存 `vision.json`（`apiKey` 传空或打码串 = 不改） | 不要 |
| POST | `/api/test` | 试看一张图/一段视频（只描述，不写账本、不占日限、不进任何输出） | 不要 |
| POST | `/api/verify-key` | 验一个 key / 模型能不能用（不动配置） | 不要 |
| GET | `/api/seen?limit=50` | 账本里最近看过的媒体 | 不要 |
| GET | `/api/archive` | 留档索引（图片 / 视频帧包） | 不要 |
| GET | `/api/stats/daily?days=14` | 按日统计（图/视频/token） | 不要 |
| GET | `/api/models` | 内置可选模型清单 | 不要 |
| GET | `/api/discover-ring` | 找本机「环形的心」库 | 不要 |
| GET / POST | `/api/data-dir` | 看 / 迁存储目录 | 不要 |
| GET / POST | `/api/fs` | 目录浏览 / 建文件夹（面板"选目录"用） | 不要 |
| GET | `/api/update/check`、POST `/api/update/run` | 查更新 / 一键更新（覆盖代码目录） | 不要 |
| POST | `/api/shutdown` | 停服务 | 不要 |
| GET | `/media/<相对路径>` | 读留档原件（限制在 `media/` 内） | 不要 |

**没有 token 鉴权**，安全性只有两层：只绑 `127.0.0.1`；带外站 `Origin` 的 POST 一律 403。所以：只能在本机调用；浏览器里的别的网页改不了配置、停不了服务。

### ② MCP 工具 / Node 函数（宿主调）

**本插件不对外注册 MCP 工具**（没有 `mcp` 段，海螺"当工具用"那条路走不通）。给宿主的入口是一个 Node 函数：

```js
import { visionNote } from 'file:///<插件根>/src/ring-vision.mjs';

const r = await visionNote({
  images: ['https://…/a.jpg'],   // 也可以 videos: ['https://…/b.mp4']
  key: 'group_123',              // 会话标识（只用于区分来源，随便你）
  sender: 'someone',             // 谁发的
  text: '',                      // 同条消息的文字；不给 images/videos 时从里面抠图链
  at: Date.now(),
}); // 永不抛错，结果看返回值
```

- 返回全场：`{ok:true, remembered:N, results:[…]}`；整体没看成时 `{ok:true, skipped:'disabled'|'no-outputs'|'no-media'|'daily-cap'|'no-model'}`（都是"正常没做"，不是错误）；只有兜底异常才 `{ok:false, error}`。
- `results[i]` 三种形状：看成了 `{url,kind,desc,points,model,ms,outputs:[{type,ok,…}]}`；跳过了 `{url,kind,skipped:'seen'|'no-ffmpeg'|'video-disabled'}`；这条坏了 `{url,kind,error}`。
- 反向：它自己是 MCP **客户端**。输出去向选 `mcp-ring` 时，会 spawn 环形的心 `mcp/server.mjs`，调工具 **`ring_ingest`**（参数 `content` / `points` / `source` / `speaker` / `at`）。这是本插件唯一用到的 MCP 工具名。

### ③ 事件 / 文件

投递出去的东西有固定形状，别的进程可以直接读：

- **Webhook**（输出适配器 `webhook`）：`POST` 一份 JSON 到你填的地址，`{event:"vision.seen", url, desc, points, chatKey, sender, at}`；非 2xx 记失败。
- **JSONL**（`jsonl`）：每次追加一行 `{ts, url, desc, points, chatKey, sender}`。
- **Markdown / SQLite**：`markdown` 追加一条笔记；`sqlite` 写进任意库的 `vision_log` 表（不存在自动建，列为 `created_at,url,kind,desc,points,chat_key,sender,extra`）。
- **留档**（只给面板和人工看，属运行数据）：
  - 图片：`<dataDir>/media/images/YYYYMMDD-HHmmss-0001-<hash8>.<jpg|png|gif|webp>`，同名 `.json` 记 `{desc,points,url,chatKey,sender,at,model,ms,hash}`。
  - 视频：`<dataDir>/media/videos/YYYYMMDD-HHmmss-0001-<hash8>/帧01.jpg…` + `analysis.json`（同上，多 `frameCount`）。
- **账本** `<dataDir>/eye.db`（SQLite，表 `seen`：`hash,url,chat_key,model,desc,outputs,created_at,ms,kind,tokens`）——去重、日限、审计都在这儿，和输出无关。
- **配置** `<dataDir>/vision.json`；**存储位置指针** `<插件根>/data-dir.json`（面板里改过目录才有）。

## 能力清单

跟 `metadata.json` 的 `capabilities` 一一对应：

1. **看图描述** —— 一张图 → 一句描述（≤60 字）+ 2~4 个要点；任何 OpenAI 兼容的 `chat/completions` 视觉接口都行。
2. **视频抽帧看** —— ffmpeg 抽 3 帧（均匀/间隔/场景），逐帧描述后合并成一条；缺 ffmpeg 就跳过视频，图片照常。
3. **动图（GIF）抽帧** —— 抽最多 3 帧当图看，按图片留档。
4. **视频音轨转文字** —— 另配任意 OpenAI 兼容 `/audio/transcriptions`（默认 Groq `whisper-large-v3`），可选；失败不影响画面描述。
5. **多路输出扇出** —— 6 个内置适配器（`ringmind` / `mcp-ring` / `sqlite` / `jsonl` / `markdown` / `webhook`）+ `custom`（自己的 `.mjs` 导出 `deliver`），可叠加，一个挂了不拖累别的。
6. **去重 + 日限 + 用量记账，以及面板**（填 key、试看、翻留档、日统计、一键更新）。

## 失败语义

先记住总原则：**看图这条链永不抛错到调用方**，一切结果都在返回值里。

1. **没配置**
   - 面板上一张图都没看：`enabled:false` → `skipped:'disabled'`；没勾任何输出 → `'no-outputs'`；模型字段空 → `'no-model'`。
   - 有接口没 key：视觉服务回 401/403，错误被翻成中文（"key 没填或不对…原始返回：…"），这条进 `results[i].error`。**HTTP `/api/test` 走外层 catch，回 500** `{ok:false,error:"视觉模型 401 —— …"}`。
   - 没 ffmpeg：视频 / 动图 → `skipped:'no-ffmpeg'`，不报错。
   - 没配 `ringmind` 的 `dbPath` 或找不到环形的心：该输出项 `{ok:false,error:'…'}`，其它输出照发。
2. **超时 / 忙**
   - 图片下载固定 20 秒超时；视觉请求默认 45 秒（`vision.json` 的 `timeoutMs`）；视频下载 120 秒；ASR 90 秒。
   - 429（限流）→ 中文"触发限流了"；可以多配几条模型通道并发分摊。
   - 端口被占：**不会自动换端口**，进程直接起不来（stderr `EADDRINUSE`）。宿主先探 `/api/health` 再启动。
3. **该重试还是放弃**
   - 网络 / 5xx / 超时：可重试。
   - 401 / 403 / 404：重试没用，先改 key / 地址 / 模型名。
   - 429：退避后重试。
   - `skipped:'seen'`：**别重试**。同一个 URL 已经看过（`eye.db` 有 hash），要重看得先把那行删掉。
4. **不可逆动作**
   - 写输出（记忆库 / SQLite / JSONL / Markdown / Webhook）：每个 `deliver` 都回 `{ok, error}`，`results[i].outputs[]` 如实带 `ok:false`，不会静默成功。
   - **注意**：投递是"先发再记账"，**输出全挂了这笔也仍然进 `eye.db`、占日限、算看过**。要重投得自己删 `seen` 里那行，否则下次被 `seen` 挡住。
   - `POST /api/update/run`：覆盖代码目录（不动 `data/`、`bin/`、`.git`），不可逆，失败会回 `{ok:false,error}`。
   - `POST /api/data-dir`：复制到新目录再切指针，不删旧数据。
   - `POST /api/shutdown`：停服务，之后所有接口连不上。

## 单独运行

不需要海螺。装 Node ≥ 22.5（用到内置 `node:sqlite`）：

```powershell
cd <插件目录>\留影
node src/panel.mjs --port 5188
# 数据目录想放别处：
node src/panel.mjs --port 5188 --dataDir D:\liuying-data
```

- 参数 / 环境变量：`--port`（或 `RING_VISION_PORT`，默认 5188）、`--dataDir`（或 `RING_VISION_DATA`，默认为插件根 `data/`）。
- 起来后开 http://127.0.0.1:5188/：填「接口地址 + 模型 + key」→ 试看一张图 → 选输出去向 → 保存。
- 想让它**自动**看消息（不是手动试看），得自己喂：用上面的 `visionNote()`，或桥接侧动态 import 后调用。**它自己不会收 QQ / OneBot 消息**——"谁来发图"由宿主决定。
- 需要什么 / 可选什么：见 `metadata.json` 的 `standalone.needs`。核心只有「Node + 一个视觉接口 key」；ffmpeg 和环形的心都是可选。

## 自检

服务在跑的时候（Windows 用 `curl.exe`，别用 PowerShell 里的 `curl` 别名）：

```powershell
curl.exe -s http://127.0.0.1:5188/api/health
curl.exe -s http://127.0.0.1:5188/api/manifest
```

期望（`uptime_s` / `pid` / `started_at` 每次不同）：

```json
{"ok":true,"id":"eyes","version":"1.8.0","uptime_s":12}
{"ok":true,"metadata":{"id":"eyes","name":"留影","version":"1.8.0",...},"runtime":{"port":5188,"pid":12345,"started_at":"2026-11-09T15:20:00.000Z"}}
```

只看通不通、状态码是不是 200：

```powershell
curl.exe -s -o NUL -w "%{http_code}`n" http://127.0.0.1:5188/api/health
```

用 Node 一遍核完（不依赖 curl）：

```powershell
node -e "const b='http://127.0.0.1:5188';Promise.all(['/api/health','/api/manifest'].map(p=>fetch(b+p).then(async r=>[p,r.status,await r.json()]))).then(x=>console.log(JSON.stringify(x,null,2)))"
```

接了海螺这套生态的，用官方检查脚本（含 health / manifest / 版本一致性）：

```powershell
cd <插件目录>\海螺
.\.venv\Scripts\python.exe scripts\compat_check.py --live
```

`version` 说明：`/api/health` 的 `version` 取自 `package.json`（自更新也认这个），必须和 `metadata.json` 的 `version` 一致；不一致就是有人改漏了。
