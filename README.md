# 留影

> **通用视觉接入插件**（独立项目）—— 给任何消息流装上「眼睛」：
> 图片 → 视觉模型看一眼 → 描述 → 交给你选的出口。
>
> 内置六个输出适配器（Ringmind 记忆库 / 通用 SQLite / JSONL / Markdown / Webhook / 自定义脚本），
> 可叠加、可换、互不拖累；想接新系统，写一个十几行的适配器就行。

## 原理

```
消息文本（含 [CQ:image,…] 或任何图链）→ 抠图链 → 下载 → 视觉模型看图
  → { 描述 ≤60字, 要点 2~4条 } → 扇出给所有启用的输出适配器
```

- 视觉模型：OpenAI 兼容接口即可（默认 **GLM-4V-Flash 免费**，可换 Qwen-VL 等）
- 去重 / 日限（默认 40 张/天）/ 审计记在**眼睛自己的 eye.db**，换输出不丢账
- 没配 key、下载失败、某个输出挂了 → 静默跳过或单独记错，绝不拖累消息主流程

## 用法

双击桌面「留影面板」（就是项目里的 `留影面板.vbs`）：

```
后台起服务（不弹黑框）→ 等服务就绪 → 自动打开 http://127.0.0.1:5188
```

面板里：填 key → 选「输出去向」（环形的心 / JSONL / Webhook / …）→ 保存 → 完成。
不用了点右上角「**关闭面板**」，服务会一起停掉，不会留后台进程。

启动器的三种情况：

| 触发 | 行为 |
|---|---|
| 双击 | 起服务 + 开浏览器 |
| 带 `/boot` 参数 | 只起服务，不开浏览器（开机自启用） |
| 服务已经在跑 | 不重复起进程，直接开浏览器 |

node 路径从 `node-path.txt` 读（UTF-8，支持中文路径），换机器只改这一个文件。

## 开发与提交

```bash
node --test tests/*.test.js      # 45 个测试，改完必须全绿再提交
```

- 提交信息用**中文**，一句话说清「改了什么 + 为什么」，动词开头，不加 `feat:`/`fix:` 前缀
- 一次改动一个提交：改完 → 跑测试 → `commit` → `push`，不要攒
- **不要**把 `data/`（含 key）、`node-path.txt`、`docs/` 提交上去
- 这台机器的 `github.com` 被 hosts 钉在不可用 IP，`push` 需要走本地代理 —— 完整做法见本地 `docs/设计-*.md` 第十二节
