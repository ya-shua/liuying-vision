# 留影

> **通用视觉接入插件**（独立项目）—— 给任何消息流装上「眼睛」：
> 图片 → 视觉模型看一眼 → 描述 → 交给你选的出口。
>
> 内置六个输出适配器（Ringmind 记忆库 / 通用 SQLite / JSONL / Markdown / Webhook / 自定义脚本），
> 可叠加、可换、互不拖累；想接新系统，写一个十几行的适配器就行。

## 原理

```
消息文本（含 [CQ:image,…] 或任何图链）→ 抠图链 → 下载 → 视觉模型看图
  → { 描述 ≤60字, 要点 2~4条 } → 扇出给所有启用的输出适配器
```

- 视觉模型：OpenAI 兼容接口即可（默认 **GLM-4V-Flash 免费**，可换 Qwen-VL 等）
- 去重 / 日限（默认 40 张/天）/ 审计记在**眼睛自己的 eye.db**，换输出不丢账
- 没配 key、下载失败、某个输出挂了 → 静默跳过或单独记错，绝不拖累消息主流程

## 用法

```
双击 启动留影.bat → 浏览器 http://127.0.0.1:5188
```

面板里：填 key → 选「输出去向」（环形的心 / JSONL / Webhook）→ 保存 → 完成。
qq-bridge 接入的三行补丁见完整文档第三节。
